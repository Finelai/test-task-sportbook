# Repository conventions

- Follow the commit, branch, and merge rules in [CONTRIBUTING.md](CONTRIBUTING.md).
- Use Conventional Commits for commit messages and Conventional Branch 1.0.0
  for branch names.
- When working from a current plan, include its scope in every commit message
  and branch name. Use a short, lowercase identifier for the plan's area of
  work, and use the same identifier consistently throughout the plan.
- Put the plan scope in the commit's scope field and at the start of the branch
  description. For example, for a wallet plan, use `feat(wallet): add balance`
  and `feat/wallet-add-balance`.
- If there is no current plan, follow the conventions in CONTRIBUTING.md
  without adding a plan scope.
